01/StackStatic, near-zero JS
Framework
Astro 6, static output. No client framework.
Styles
Vanilla CSS with custom properties and container queries. One stylesheet.
Content
MDX content collections with typed front matter for posts and case studies.
CMS
Sveltia CMS at /admin. Git-backed, so every edit is a commit.
Hosting
Cloudflare. Headers set in one file in the repo.
Type
Geist Sans, Geist Mono and Geist Pixel Square, self-hosted under the SIL Open Font License.
Analytics
None. Not even the privacy-friendly kind.
