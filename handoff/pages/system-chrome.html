Behaviour

Native <dialog> with showModal(). Focus starts in the prompt and is trapped until Esc. Arrow keys move aria-activedescendant. The index is a small JSON file built at compile time, about 4 kB, fetched on first open only.

States

Empty: shows recent pages. No match: "command not found: query" in --muted with a hint to try a tag. Selected row: --surface-2 and an accent caret.

No JS

The trigger is a link to /log with the search field focused, so it still works.

Mobile

Opens full width from the top, 16px gutters. Trigger lives in the menu sheet.
